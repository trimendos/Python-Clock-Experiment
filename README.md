This project, Clock Experiment, is a comparative study of different threading and timing mechanisms in Python. It evaluates the performance and behavior of various approaches, including QThreadPool, QTimer, Thread, and ThreadPoolExecutor, for implementing clock-based functionalities. The project uses Python and Nuitka for building and optimizing the executables, and it includes visual performance comparisons and detailed build artifacts for each approach.
# How to Run
## Setup Environment:

Install Python 3.13 or later.
Create a virtual environment and install dependencies.

python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
